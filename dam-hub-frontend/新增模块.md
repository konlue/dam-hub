## AI 搜图（策展助手）前端对接文档

### 一、接口说明

**请求地址：** `POST /api/ai/search`

**请求体：**

| 字段       | 类型    | 必填 | 说明                                         |
| ---------- | ------- | ---- | -------------------------------------------- |
| `query`    | String  | 是   | 用户输入的自然语言需求，如"科技感的横幅背景" |
| `topK`     | Integer | 否   | 返回结果数量，默认 5                         |
| `spaceId`  | Long    | 否   | 空间ID，用于权限过滤                         |
| `category` | String  | 否   | 分类过滤                                     |
| `color`    | String  | 否   | 颜色过滤                                     |

**请求示例：**

```
{
  "query": "给电商大促准备一组科技感的横幅和背景图",
  "topK": 5
}
```

### 二、页面需求

**页面位置：** 建议在素材广场或图片列表页新增一个 AI 搜图入口（可放在搜索栏旁边，用独立 Tab 或按钮触发）。

**核心交互：**

1. **搜索输入区** — 一个文本输入框 + 搜索按钮，用户输入自然语言描述（如"给我找几张适合年终总结的商务风背景"）

2. **意图分析展示**（可选） — 搜索返回后，展示 AI 解析出的行业/用途/场景/风格标签，让用户知道 AI 理解了什么

3. 推荐结果列表

    — 卡片式展示图片，每个卡片包含：

   - 图片缩略图（用 `pictureId` 查你们现有的图片接口拿 url）
   - 标题
   - 分类标签
   - AI 推荐理由（`reason` 字段）
   - 相关度得分（`score`，可展示为百分比或星级）

4. **策展方案** — 在结果列表上方或下方展示 `answer` 字段的总结文案，作为 AI 的整体推荐说明

5. **加载状态** — 这个接口涉及 LLM 调用，响应可能需要 3-10 秒，需要 loading 动画

**交互细节：**

- 搜索框支持 Enter 键触发
- 结果为空时给出友好提示
- `recommendations` 里的 `pictureId` 需要调用你们现有的图片详情接口拿到真实 URL 来展示
- 建议加一个"换一批"或"重新生成"按钮，重复调用同一接口

------

### 三、后端说明（给前端的补充）

- 请求经过 Spring Boot 后端 `/api/ai/search` 转发到 AI 微服务，前端**直接调后端接口即可**，不需要直连 AI 服务
- 响应时间较长（3-10s），后端会做超时处理，前端做好 loading 即可
- 该接口不需要额外鉴权，复用现有的登录态
